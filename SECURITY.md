# Politica de securitate

## Raportarea unei vulnerabilități

Nu deschide un issue public pentru probleme de securitate.

Folosește raportarea privată din fila **Security → Report a vulnerability** a acestui depozit:
<https://github.com/VIK-DD/egov4schools/security/advisories/new>

Include, pe cât posibil:

- descrierea problemei și impactul estimat;
- pașii de reproducere sau o dovadă de concept;
- versiunea (commit-ul) afectată.

## Versiuni suportate

Doar ramura `main` primește corecții de securitate.
